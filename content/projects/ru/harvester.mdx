## О проекте

HARVESTER — это демо-приложение, продвигающее инструмент EPAM для определения архитектуры решений и\u00A0расчёта извлечения энергии из окружающей среды. Он предоставляет инженерам и\u00A0архитекторам практические инсайты для проектов по сбору энергии в\u00A0IoT.

![Промо-сайт HARVESTER — главная страница с\u00A0hero-секцией и\u00A0логотипами партнёров](/images/cases/hrvstr/01.png)

![Сайт HARVESTER на MacBook — hero-секция с\u00A03D-визуализацией устройства](/images/cases/hrvstr/macbook-1-1.png)

## Задача

Создать видение унифицированного решения для подготовки пре-сейлов и\u00A0проектирования систем сбора энергии. Обеспечить оригинальный контент и\u00A0визуальные решения для сложных инженерных кейсов.

![Секция сайта «Что мы делаем» — таб «Проблема» с\u00A0обзором доступности энергии для IoT](/images/cases/hrvstr/whatwedopromo01.png)

## Моя роль

Старший дизайнер, ответственный за тесное сотрудничество с\u00A0инженерами, развитие продуктового видения, приоритизацию функций и\u00A0преобразование сложных технических концепций в\u00A0интуитивно понятные интерфейсы.

## Процесс

### Приоритизация функций

Разработан трёхуровневый фреймворк приоритизации, разделяющий функции на необходимые, важные и\u00A0опциональные. Это позволило команде сосредоточиться на предоставлении основной ценности в\u00A0первую очередь, планируя прогрессивное развитие платформы.

### Пользовательские сценарии и\u00A0кейсы

Разработаны подробные пользовательские сценарии и\u00A0созданы три комплексных кейса для различных сред — внутри помещений, в\u00A0городских условиях и\u00A0в\u00A0удалённых/промышленных зонах. Каждый кейс демонстрировал уникальные паттерны сбора энергии и\u00A0архитектурные решения.

![Примеры энергетического баланса — кейсы мониторинга лесовосстановления и\u00A0умного управления отоплением](/images/cases/hrvstr/06.png)

![Примеры энергетического баланса на MacBook](/images/cases/hrvstr/macbook-1-2.png)

### Интеграция данных сенсоров в\u00A0реальном времени

Спроектированы интерфейсы для визуализации данных сенсоров в\u00A0реальном времени, созданы интуитивно понятные дашборды, отображающие метрики сбора энергии, параметры окружающей среды и\u00A0индикаторы производительности системы в\u00A0легко воспринимаемом формате.

![Калькулятор энергетического баланса — схема с\u00A0поставщиками и\u00A0потребителями энергии](/images/cases/hrvstr/02.png)

![Калькулятор энергетического баланса — четыре вида: Схема, Таблица, Баланс и\u00A0мобильная адаптация](/images/cases/hrvstr/04.png)

![Калькулятор энергетического баланса на MacBook — вид «Схема»](/images/cases/hrvstr/macbook-4.png)

### Кастомная иконография

Разработано и\u00A0создано более 40 кастомных иконок, представляющих различные источники энергии, сенсоры, архитектурные компоненты и\u00A0факторы окружающей среды. Создан целостный визуальный язык, делающий сложные инженерные концепции доступными для нетехнических стейкхолдеров.

### Дизайн-система

Создана комплексная дизайн-система по методологии Atomic Design — от цветовых токенов и\u00A0типографики до сложных интерактивных компонентов для энергетического калькулятора.

![Компоненты дизайн-системы — типографика, цветовые токены, кнопки, формы и\u00A0карточки](/images/cases/hrvstr/03.png)

![Обзор UI Kit — полная библиотека компонентов с\u00A0формами, навигацией, модальными окнами и\u00A0карточками источников энергии](/images/cases/hrvstr/05.png)

![Дизайн-система на MacBook](/images/cases/hrvstr/macbook-2.png)

### Интерактивное прототипирование

Созданы интерактивные прототипы ключевых компонентов, включая анимированные карточки источников энергии с\u00A0визуализацией данных в\u00A0реальном времени, позволяющие стейкхолдерам оценить продукт до начала разработки.

![Прототип анимированной карточки — интерактивный компонент выбора источника энергии](/images/cases/hrvstr/card-animated.png)

## Результаты

Создана комплексная дизайн-система, выстроен эффективный дизайн-процесс и\u00A0сформирована слаженная команда. Создан качественный промо-сайт наряду с\u00A0продуктовым решением и\u00A0масштабируемой дизайн-системой, способной вместить будущее расширение функциональности.

![Hero-секция сайта HARVESTER — оригинальная концепция](/images/cases/hrvstr/hero.png)

## Ключевые выводы

Осознана ценность модульного прогрессивного планирования при работе со сложными инженерными предметными областями. Развиты навыки эффективной коммуникации с\u00A0инженерами и\u00A0перевода технических требований в\u00A0дизайн-решения. Выстроены масштабируемые дизайн-процессы, способные расти вместе с\u00A0проектом.
