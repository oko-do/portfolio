## About the Project

CodeArts IDE is a powerful integrated development environment developed by Huawei for Java, Python, and C++ development. The product received the prestigious iF Design Award, recognizing its excellence in user experience and interface design within a highly technical domain.

## The Challenge

Create core IDE features — code editing, debugging, and version control — with a strong focus on usability and customization. Ensure the IDE is accessible, lightweight, and responsive across different hardware configurations.

## My Role

As Lead Designer, I was responsible for user research, design and development of key IDE features, cross-functional collaboration with engineering and product teams, prototyping, usability testing, and accessibility compliance.

## Process

### Research & Developer-Centric Insights

I conducted extensive research into developer workflows, pain points, and mental models. I interviewed professional developers working with Java, Python, and C++ to understand context-switching patterns, debugging habits, and customization needs that informed the design direction.

### Design System & Storybook Implementation

I built a comprehensive design system with reusable components tailored for IDE interfaces — code editors, panel layouts, tree views, terminal emulators, and toolbar patterns. Integrated with Storybook for real-time component previews and developer handoff.

![Design system: reusable components for IDE interfaces](/images/cases/codearts-ide/design-system.png)

### Custom Icon System

I designed a custom icon set optimized for IDE context — clear, legible at small sizes, and consistent across all tool windows and panels.

![Custom icon set for IDE tools and panels](/images/cases/codearts-ide/icons.png)

### Contextual Features

I worked closely with engineers when designing contextual features (e.g. Peek Usages — navigate references without losing current context). I accounted for the specifics of different tech stacks: we analysed patterns of Java and Python developers and validated hypotheses through concepts to find the most universal and flexible solution.

![Peek Usages: quick reference navigation without switching files](/images/cases/codearts-ide/peek-usages.png)

### Theme System & Debugger

I designed a flexible theming system that supports multiple color schemes while maintaining readability and accessibility in code editing and debugging interfaces.

![Debugger interface with multiple theme options](/images/cases/codearts-ide/debugger-themes.png)

### AI Features Integration

I designed the user experience for AI-powered features including intelligent code completion, code explanation, and automated refactoring suggestions — ensuring they enhance rather than disrupt the developer's flow.

![AI-powered features: code completion, explanation, and refactoring](/images/cases/codearts-ide/ai-features.png)

### A/B Testing & Data-Driven Decisions

I implemented A/B testing for key interface decisions to validate design hypotheses with real usage data before rolling out changes to all users.

## Results

- Successful IDE release with significantly improved UX compared to competitors
- Created a reusable design system that accelerated feature delivery
- Enhanced collaboration between distributed design and engineering teams
- Implemented data-driven improvements via A/B testing, resulting in the iF Design Award recognition

## Key Learnings

Initial lack of familiarity with developer workflows was a significant challenge that I overcame through immersive research. The highly technical domain required deep engagement with the subject matter. Balancing usability improvements with technical constraints of a desktop application demanded creative problem-solving and constant negotiation with engineering.
